## Godot 导入与组合约定

- 运行时贴图源文件保留在 `assets/`，`.import` 配置与 `.uid` 随版本控制；`.godot/` 导入缓存由编辑器重新生成。
- UI 和透明对象采用无损 PNG、线性过滤；仅在缩小时确有闪烁的资源上启用 mipmap。按实际显示尺寸选择贴图，避免小控件占用大纹理内存。
- 背景、棋盘底材、木框、爪印、角色、卡片、文字和前景装饰分开存放。装饰节点忽略鼠标输入；棋盘网格与点击映射共用 `BoardView` 的内部网格矩形。
- 空白木牌、黑板、卡片、气泡及立牌不烘焙可变文字。双层卡片和气泡本轮按固定版式整体缩放，动态文字为独立标签；角色与道具保持宽高比。
- 资源导入后检查 Alpha 边缘、主体中心、光向、重复格线、贴图拉伸和 Godot 报错。原型合成图仅用于对照。
