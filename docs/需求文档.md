## 1. 产品定位

### 1.1 一句话定位

**一款只看一眼就想点开的萌宠五子棋。** 功能极简（本地对局 + 人机），体验极重（UI / 动效 / 音效）。

### 1.2 设计基调

**萌，但不日系。**

- 拒绝「酱 / 君 / chan」那套二次元腔调与视觉符号。
- 两条并行的萌系路线：
  - **中文原生萌**：五宝 / 小五宝 —— 无舶来语感，纯中文语境的可爱。
  - **西式卡通萌**：Fivey —— 欧美绘本 / 黏土动画式的敦厚可爱。
- 原型图实际呈现的是二者融合：**3D 黏土质感的中华田园萌宠 + 暖调木质场景**，作为主视觉基准。

### 1.3 目标用户

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 轻度休闲玩家 | 睡前 / 摸鱼 / 等人，3–10 分钟 | 打开即玩，不需要学规则，看着舒服 |
| 亲子 / 朋友同屏 | 一台设备两人轮流 | 上手门槛为零，孩子能看懂 |
| 系列老玩家 | 玩过 MoeChess，来收第二作 | 熟悉的美术语言，新的棋种 |

### 1.4 体验目标（非功能层面的"感觉"）

- **前 3 秒**：画面本身要能留住人 —— 场景里有会呼吸的小动物，有暖光和热气。
- **前 10 秒**：不用读任何说明就敢落第一子。
- **每一手**：落子有反馈（视觉 + 触感 + 声音），不能"点下去没动静"。

## 3. 功能需求

### 3.1 对局模式

#### 3.1.1 双人对战（F1）

| 项 | 规格 |
|---|---|
| 参与者 | 玩家一（先手）、玩家二（后手），同设备 |
| 落子顺序 | 严格交替，先手方不可跳手 |
| 棋盘规格 | 15 × 15 交叉点棋盘 |
| 列坐标 | A–O（左→右，共 15 列） |
| 行坐标 | 1–15（下→上，1 在底部，符合棋类惯例；与原型图一致） |
| 星位 | 5 个（天元 + 四角星位），与原型图一致 |
| 回合提示 | 当前行动方的名牌高亮 + 气泡文案切换 + 角色小幅前倾 |
| 计时 | **无**。不设走子倒计时，不读秒 |

#### 3.1.2 人机对战（F2）

| 项 | 规格 |
|---|---|
| 玩家执子 | 固定玩家先手（黑）、AI 后手（白） |
| 难度 | 三档：**萌新 / 普通 / 高手**，开局前选择，对局中不可切换 |
| 思考耗时 | 上限 ≤ 800ms（高手档），超出则走当前最优候选，不卡界面 |
| 思考表现 | AI 侧角色进入"思考态"（歪头 / 眨眼频繁 / 头顶省略号气泡），**不显示进度条** |
| 落子节奏 | AI 应手最少延迟 350ms 再落子（避免"秒回"失去博弈感与可读性） |
| 认输 | 玩家可认输；AI **不会**认输（哪怕必败，也走完） |

### 3.2 落子与胜负判定

| 项 | 规格 |
|---|---|
| 落点判定 | 以交叉点为准；渲染格与判定格 1:1，**不允许**视觉偏移（触屏尤其重要，需放宽容错半径，见 §8.3） |
| 合法性 | 仅允许落在空点；已有棋子的点点击无效（但要有"点不动"的拒绝反馈：轻微摇头 + 短促音） |
| 胜负 | 任意一方在横 / 竖 / 斜（两向）形成**连续 5 子**即胜 |
| 长连 | 6 子及以上长连**同样判胜**（休闲版，无禁手） |
| 和棋 | 225 个交叉点全部填满且无五连 → 和棋 |
| 连珠确认 | 成五后强制中断落子，播放连珠高亮动效 + 胜利音效，再进结算 |
| 撤销影响 | 胜负判定必须可随悔棋**完全回退**（见 3.3） |

### 3.3 无限悔棋（F3）

**这是本作一个必须做扎实的功能，语义要明确。**

| 项 | 规格 |
|---|---|
| 次数 | 无限制，可一直悔到开局第一手之前（棋盘全空） |
| 触发 | 对局中任意时刻可点击「悔棋」按钮/图标 |
| 双人模式语义 | **撤一手**：撤销对方（上一手）刚落下的一子，行动权回到对方 |
| 人机模式语义 | **撤一回合**：撤销玩家上一手 + AI 的应手，回到玩家上次决策前的局面 |
| 边界 | AI 尚未应手时悔棋 → 只撤玩家那一手；棋盘已空时按钮置灰 |
| 动画 | 被撤棋子**弹性缩小并飞回**对应玩家侧（暗示"收回"），而非生硬消失；随后落点高亮环淡出 |
| 音效 | 独立"撤回"音效（上行/倒放质感），不与其他音效复用 |
| 状态回退 | 必须同步回退：棋盘状态、行动方、连珠判定缓存、AI 搜索缓存、手数统计 |
| 结算后 | 已进入结算层则不可悔棋（结算层只提供"再来一局 / 返回主页"） |
| 建议（可选） | 结算面板可展示"本局悔棋 N 次"作为趣味统计 —— 非必做，见 §12 决策点 D4 |

> ⚠️ 设计约束：悔棋**不得**破坏胜负判定的正确性。实现上要求棋盘状态机支持完整回滚，禁止只在 UI 层擦除棋子。

### 3.4 认输（F4）

| 项 | 规格 |
|---|---|
| 触发 | 对局中点击「认输」 |
| 二次确认 | **必须**二次确认（防误触），确认弹窗走萌系话术，不用"确定/取消"这种干巴词 |
| 结果 | 认输方判负，对方胜 |
| 表现 | 认输方角色露出"软萌失落"（下垂耳朵 / 低头），**禁止**任何嘲讽、打击式表达 |
| 与悔棋关系 | 认输瞬间关闭悔棋入口 |

### 3.5 对局状态机

```
主页
 └─ 选模式（双人 / 人机）
     └─ [人机] 选难度
         └─ 对局中 ──┬─ 落子 ──→ 判定
                     │            ├─ 未成五 → 切换行动方 → 对局中
                     │            ├─ 成五   → 连珠动效 → 结算
                     │            └─ 盘满   → 结算（和棋）
                     ├─ 悔棋 ──→ 回退状态 → 对局中
                     ├─ 认输 ──→ 确认 → 结算
                     └─ 结算 ──┬─ 再来一局 → 对局中（清盘、保留模式与难度）
                               └─ 返回主页 → 主页
```

## 4. UI 设计规格（重点）

### 4.1 视觉基准

**基准资产：`docs/原型图.png`** —— 本节的布局与色彩均以该图为取样来源。

整体印象：**暖色木质 × 黏土萌宠 × 室内角落**。不是冷色调的"科技棋盘"，而是像放在窗边桌上的一个实体玩具。

### 4.2 色彩系统（自原型图取样，待美术定稿）

| 用途 | 色值（约） | 说明 |
|---|---|---|
| 场景底色 / 墙面 | `#EFDCC0` → `#C9A279` | 暖米到木棕的渐变底 |
| 棋盘木底 | `#E8BC7E` → `#D9A05B` | 浅木纹，中心略亮 |
| 棋盘线 / 星位 | `#8B5E3C` | 深棕细线，非纯黑 |
| 棋盘边框 | `#B07B45` | 厚木框 + 圆角 |
| 玩家一（主色） | `#A9714B` + 奶白 `#FFF6E9` | 小狗方，暖棕 |
| 玩家二（主色） | `#8FB6DC` + 灰白 `#F5F7FA` | 小猫方，雾蓝 |
| 强调 / 交互高亮 | `#E8863C` | 按钮、连珠光带、可落点提示 |
| 植物绿 | `#8FB573` | 场景点缀 |
| 文字主色 | `#5A3A22` | 深棕，禁止纯黑 `#000` |
| 文字反白 | `#FFF9F0` | 深底上的字 |

**规则：**
- 全局**不使用纯黑**（`#000`）与纯白（`#FFF`），一律用暖调近似色。
- 界面层级靠"木牌厚度 / 光影"，不靠描边和阴影堆叠。

### 4.3 材质与光影

| 元素 | 材质规格 |
|---|---|
| 背景场景 | 黏土质感（3D clay look），柔和次表面散射感，光源来自右上窗（暖白） |
| 棋盘 | 浅木纹，哑光，圆角边框，四角爪印浮雕装饰 |
| 棋子 | 圆润扁球（非扁平淡圆），黑子为暖黑 `#3B3430`、白子为奶白 `#FFF6E9`，带高光点与接触阴影 |
| 名牌 / 招牌 | 木质挂牌 + 麻绳/铁艺挂件，微倾角，带投影 |
| 按钮 | 圆角木质/陶瓷质感，按下有物理下压位移（视觉厚度减少） |
| 气泡 | 手绘感圆角气泡，带小尾巴，轻微投影 |

> 原型图顶部左侧为挂式木牌标题（"五子棋 · 以棋会友·快乐常在"），右上为小黑板（"下好每一步·遇见更好的自己"）—— 二者作为**场景固定装饰**保留，文案可轮换（见 §12 决策点 D5）。

## 5. 美术动效规格（重点）

### 5.1 动效原则

1. **动效服务于"手感"**，不是炫技。每个动效都要回答："它让玩家更清楚地感知到了什么？"
2. **短**。落子类反馈 ≤ 250ms，界面转场 ≤ 400ms。超出即在拖累节奏。
3. **有重量**。棋子落下要有"啪"的实体感（弹性曲线 + 接触阴影收缩），不能匀速平移。
4. **可打断**。连点落子时，前一个动效必须能立即让位给下一个（不排队卡顿）。
5. **不闪不抖**。禁止高频闪烁、剧烈抖动 —— 面向休闲用户，避免眩晕。

### 5.2 动效清单

| # | 名称 | 触发 | 表现 | 时长 | 优先级 |
|---|---|---|---|---|---|
| A1 | 棋子落下 | 任一方落子 | 从上方 1.2 格高处落下 → 接触瞬间轻微压扁（squash）→ 回弹到正常 | 220ms | P0 |
| A2 | 最后一手高亮 | 落子完成 | 呼吸环缓慢放大淡出，循环 | 1.6s 循环 | P0 |

## 6. 音效规格（重点）

### 6.1 音频原则

1. **萌而不吵**。可爱靠音色圆润度（木质、软起音），不靠尖细高频。**禁止**尖锐电子音与超标高频。
2. **重复不烦**。落子音是全场播放次数最多的音（一局可达上百次），必须做 **3–4 个随机变体**（音高微差 ±5%）轮流播放，避免机械重复感。
3. **反馈即时**。音效触发延迟 ≤ 30ms，与动效帧对齐。
4. **可关**。BGM 与音效**独立开关**，且默认状态需在 §12 决策点 D6 拍板。
5. 音量上，音效整体略高于 BGM（约 +3dB），保证落子声清晰。

### 6.2 音效清单

| # | 事件 | 音色描述 | 时长 | 优先级 |
|---|---|---|---|---|

## 7. AI 对手规格

### 7.1 难度分级

| 档位 | 名字 | 行为特征 | 目标体验 |
|---|---|---|---|
| Lv1 | 萌新 | 优先堵活三；对活四/双三有概率漏看（约 25%）；带随机性 | 新手能赢，获得信心 |
| Lv2 | 普通 | 完整攻防棋型评估 + 浅层搜索；不漏活四；会做双威胁 | 有来有回，需要思考 |
| Lv3 | 高手 | 深层搜索 + 候选点裁剪 + 置换表；会主动做双三/四三杀 | 认真下才有机会 |

> 三档**共享同一套评估函数**，仅通过搜索深度、候选点宽度、失误概率参数区分，避免三套逻辑分叉维护。

### 7.2 算法方向

- 基础：**棋型模式匹配评分**（成五 / 活四 / 冲四 / 活三 / 眠三 / 活二…）+ **Alpha-Beta 剪枝**。
- 优化：候选点限制在上次落子邻域（±2 格）内按启发值排序，取前 N 个做搜索。
- 加分项（P1）：置换表（Zobrist 哈希）避免重复局面计算。
- 约束：单次思考 ≤ 800ms；计算放后台线程，**不得阻塞渲染**。

### 7.3 体验要求

- AI 落子前有**可感知的"思考"表现**（A7），不能瞬落。
- AI 的强度不追求职业级，**追求"像个人在陪你下"**：AI 也不该完美无缺。
- 若 AI 已形成必胜，仍要走完（不自动摊牌），保留玩家认输的主动权。

## 10. 验收标准

### 10.1 功能

- [ ] 双人模式可完整对局至分出胜负，行动方交替无错乱
- [ ] 人机三档难度均可正常对局，AI 无非法落子、无超时卡顿
- [ ] 悔棋：可连续悔至空盘；悔棋后棋盘状态、行动方、胜负判定全部正确回退
- [ ] 悔棋后可再次正常成五并正确判胜（**重点回归项**）
- [ ] 认输经二次确认后正确判负，认输后无法悔棋
- [ ] 横 / 竖 / 双斜四个方向成五均能判定；长连（6 子）判胜；盘满判和
- [ ] 非法落子有拒绝反馈，不改变任何状态

### 10.2 体验（本作核心验收项）

- [ ] 每个落子动作同时具备：动效（A1）+ 音效（S1/S2）+ 最后一手高亮（A2），**三者同步无缺失**
- [ ] 连续快速落子 20 手，无动画卡顿堆积、无音效吞音
- [ ] 角色待机动画（A6）在 30s 内至少触发 3 次眨眼与 1 次肢体微动
- [ ] 连续触发落子音效 100 次，主观无"机械重复"感（随机变体生效）
- [ ] 静音状态下所有功能可正常使用
- [ ] 在 6 个平台上均无布局错位、无内容被裁切、无遮挡操作区

### 10.3 性能

- [ ] 中端手机上对局全程帧率 ≥ 30fps
- [ ] 低配档降级后仍保留 A1/A2/A3/A9 四项核心手感动效
- [ ] AI 单步思考耗时 ≤ 800ms，思考期间界面无卡死
